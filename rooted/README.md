# Rooted

A personal trainer + physical therapist app for one person. Open it, press **Start**, follow along. It plans every session, filters every exercise through her body history, and never shames a missed day.

Installable PWA (phone + desktop browser), fully offline after first load, all data on-device.

## Run it

```bash
cd rooted
npm install
npm run dev        # http://localhost:5173
npm test           # 64 unit + integration tests
npm run build      # production build with service worker in dist/
npm run preview    # serve dist/ on http://localhost:4173
```

Deploy `dist/` to any static host (Netlify, Vercel, GitHub Pages). Add it to the phone's home screen for the installed experience.

### Acceptance criteria and where they are proven

- Excluded exercises can never appear in any plan or swap: `src/domain/safety.test.ts` generates 24 weeks of sessions under several safety contexts and checks every prescription and every chained swap.
- Sabbath never has a session, week-of and day-of switching rebuild correctly: `src/domain/schedule.test.ts`, `src/db/program-service.test.ts`.
- A missed session shifts forward without doubling up: same files.
- Works fully offline after first load: verified with a headless-Chromium offline reload against the production build.
- A full session runs Today → Start → Finish with no decisions: verified with a scripted walkthrough (56 taps, all "Start", "Done", "Save").

## Demo media

Every exercise ships with a calm stance pictogram (`public/media/stance-*.svg`, generated by `scripts/gen-pictograms.mjs`). To layer real GIF demos on top, run:

```bash
EXERCISEDB_API_KEY=... node scripts/fetch-exercisedb.mjs
```

It downloads matching ExerciseDB GIFs into `public/media/gifs/` and writes `public/media/manifest.json`; the app prefers a manifest entry when one exists. Custom videos for PT exercises are uploaded in-app and stored in IndexedDB.

## Decisions still needed

Search the code for `DECISION NEEDED`. The main ones:

- ExerciseDB licensing before shipping their GIFs.
- Reminders are a local setting only; real scheduled notifications need a push service or a native wrapper.
- Voice uses the browser's Web Speech voices. `src/coach/tts.ts` is the swap point for a better TTS.
