# The Loop Map / The Chrysalis Loop — build notes (2026-11-13)

Jen's spec, built as one shared module (`modules/loops`) mounted twice: Re-Centered at `/love-and-release/loops` (Shire theme: stepping stones, lantern, hobbit-folk) and Metamorphosis at `/metamorphosis/loops` (vine, leaves, butterfly, caterpillar and chrysalis). Data per profile (`lp*` tables), sharing per loop at three levels enforced in `convex/loops/entries.ts`: private, name only (`sharedSummary`), with signal (`shared`). The spouse never edits and never sees marks, notes, beliefs, or inner-kid entries.

Built, in the spec's order: data model and sharing; the guided builder with templates (full, habit, people-pleasing, blank); the ring (`Ring.tsx`, inline SVG, exit ramps wider and brighter on early stages, "you are here" marker, lookout flags, pinned belief and truth near The Story, kid figures, spiral mode with past passes, reduced motion respected, 44px targets); check-in (stage, intensity, note, exits and an encouragement line right after, "how did it go?" an hour later, retro log); exits (starter library per stage kind, custom at the top, pin, hide, "try one now", did-it-help, best float up); the encouragement deck with user cards and "hear from Coach / Mom / Dad / the mentor" (`convex/loops/encourage.ts`); the beliefs workshop with the faith step behind a per-profile toggle (on for the Shire mount, off for Metamorphosis); needs per stage with healthier ways; new-path habits (max three); guardrails (body, thought, behavior, situation with HALT, if-then, tripwire nudges on chosen days and hour via hourly cron, snooze); inner kids (child, teen, placement on the ring, family-line fields); Learn (12 brain, 12 psychology, 15 faith cards in `core/loops/learn.ts`, stage tags, "why this happens" strip on each stage, paired "read all three", Truths I Need); patterns (catch-point dots, early-catch count, median recovery, hour and day counts, month-over-month line, no streaks); spouse signals (`/loops/signal/[id]` with three kind replies); weekly review; prayer journal; safety footer on every screen.

Connections: Talk this through opens `/talk?place=tend&about=…` with loop name and stage only; people-pleasing loops link to the fawn alarm in Re-Centered; Learn's faith cards link to The Well's reader. Fonts are served by Next from the site itself (no third-party CDN), so Brave Shields is fine.

Not built: nothing from the spec is left out, except that scripture is shown as a close plain rendering with a link to the text in The Well rather than a fixed translation, and the "Hear from" voices are the coach, Mom, Dad (Shire) and the coach, the mentor (Metamorphosis).
